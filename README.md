# 🔍 Github User Finder

A simple and interactive **Github User Finder** built using **HTML, CSS, JavaScript**.

This project uses the **Github API** to search for Github users and display their profile information dynamically.

## ✨ Features

- 🔍 Search Github users by username
- 👤 Display profile picture
- 📝 Display user's name and username
- 📖 Display Github Bio
- 📍 Display User Location
- 👥 Display followers and following
- 📚 Display public repositories
- 🔗 Dispaly the user's Github Profile
- ⚠️ Handle invalid usernames
- 🚫 Validate empty input
- 📱 Responsive design
