# 🔍 Github User Finder

A simple and interactive **Github User Finder** built using **HTML, CSS, JavaScript**.

This project uses the **Github API** to search for Github users and display their profile information dynamically.

## ✨ Features

- 🔍 Search Github users by username
- 👤 Display profile picture
- 📝 Display user's name and username
- 📖 Display Github Bio
- 📍 Display User Location
- 👥 Display followers and following
- 📚 Display public repositories
- 🔗 Dispaly the user's Github Profile
- ⚠️ Handle invalid usernames
- 🚫 Validate empty input
- 📱 Responsive design

## 🛠️ Technologies Used 

- **HTML5** - To create the structure of the application.
- **CSS3** - To style the application and make it responsive.
- **JavaScript** - To implement search functionality and dynamic updates.
- **GitHub REST APi** - To fetch Github user information.
- **Fetch API** - To send requests to the Github API.
- **Async/await** - To handle asynchronous operations.
- **JSON** -  To process API response data.
- **DOM Manipulation** - To display user information dynamically.

## 🔌 API Used

This project uses the GitHub REST API  to retrieve public Github User information.

**API Endpoint:** 

'https:/api.github.com/users/{username}'

The username entered by the user is added dynamically to the API URL.
